# AI와 내 판단 3줄 (C60)

> **이 문서는 사용자가 직접 작성한다.** AI가 대신 채우면 과제의 의미가 사라진다.
> 아래 3항목을 각각 나누어 적어야 통과다.

## ① AI에게 맡긴 일

과제 요구사항 분석, 데이터베이스·API·플래너 화면 구현, 자동 검사와 문서 정리를 AI에게 맡겼다.

## ② 내가 직접 판단한 일

Vercel에서 Supabase 데이터베이스를 만들고 연결했으며, 실제 계획·할 일·실행 기록의 내용은 내가 직접 정해 입력했다.

## ③ AI 제안을 따르지 않은 일

계획과 할 일을 별도 화면에서만 입력하는 초기 흐름을 그대로 두지 않고, 사용하기 편하도록 플래너 화면에서도 바로 추가하게 수정하도록 요청했다.
