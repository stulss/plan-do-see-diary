# 검증 안내서 — 30초 안에 끝내는 확인

> 현재 상태(2026-09-01): 자동 검사 9건·타입 무결성·프로덕션 빌드, 플래너 3개 뷰(일/주/월), 계획 수정 이력, 완료 중복, 돌아보기 집계와 근거 목록, 이월 계획, JSON 내보내기, 비밀값 검색, 스크립트 문자 실제 표시를 검증 완료했다. 배포 주소 시크릿 창 확인만 남아 있다.

## 짧은 확인 방법 4줄 (제출용, C59)

**① 어디로 가나요**
배포 주소의 첫 화면 `/` (로그인·가입 없이 바로 열립니다)

**② 세 단계 안에 무엇을 하나요**
1. 할 일 목록에서 아무 할 일의 **완료** 버튼을 빠르게 두 번 누른다
2. 위쪽 메뉴에서 **돌아보기**로 이동한다
3. **완료 수** 숫자를 클릭한다

**③ 무엇이 보이면 통과인가요**
완료 수가 **1만** 늘어 있고, 그 숫자를 누르면 방금 완료한 할 일이 포함된 목록이
"○○기간의 완료 N건"이라는 조건 문장과 함께 보인다. 새로고침해도 값이 그대로다.

**④ 안 될 때는 무엇이 보이나요**
화면 위쪽에 오류 띠가 뜨고 "저장하지 못했습니다 — 다시 시도" 문구가 보인다.
빈 화면이나 아무 반응 없음은 정상이 아니다. 이 경우 새로고침 후 다시 시도한다.

## 항목별 확인 절차

| 확인할 것 | 절차 | 통과 기준 |
|---|---|---|
| 계획 이력 (C08) | 계획 상세 → 제목 수정 → 저장 → 하단 이력 확인 | 고치기 전 값이 이력에 남아 있다 |
| 정렬 (C20) | 할 일 목록에서 새로고침 2회 | 화면에 적힌 기준대로, 순서가 매번 같다 |
| 완료 멱등 (C21/C22) | 완료 버튼 연타 → 돌아보기 | 기록 1건, 완료 수 +1 |
| 실행 기록 분리 (C27) | 실행 기록 추가 후 할 일의 예상 시간 확인 | 예상 시간이 그대로다 |
| 지연 수 (C30) | 마감일이 지난 미완료 할 일 확인 | 완료된 건은 지연으로 세지 않는다 |
| 되짚기 (C83) | 집계 숫자 클릭 | 목록 건수 = 집계 숫자, 조건 문장 표시 |
| 이월 (C33) | 돌아보기에서 한 줄 작성 → 계획 만들기 | 계획 폼에 그 문장이 채워지고, 계획 상세에 출처가 보인다 |
| 새로고침 복원 (C35) | 자료 입력 후 F5 | ID·날짜·값·단위가 동일 |
| 내보내기 (C36) | `/api/export` 접속 | JSON 파일 1개가 내려받아진다 |
| 스크립트 문자 (C57) | 제목에 스크립트 모양 글자 입력 후 저장 | 실행되지 않고 글자 그대로 보인다 |
| 비밀값 (C58) | 개발자 도구 소스·네트워크·콘솔 검색 | 접속 문자열이 어디에도 없다 |
| 공개 접근 (C01) | 새 시크릿 창에서 결과물·소스 주소 열기 | 인증 없이 열린다 |
