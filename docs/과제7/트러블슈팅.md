## 미리 알아 둔 함정 (겪으면 위 형식으로 옮겨 적는다)

| 예상 함정 | 먼저 볼 곳 |
|---|---|
| 로그아웃했는데 예전 쿠키로 계속 들어와진다 | 서버에서 `user_session` 행을 정말 지웠는지 → 쿠키만 지우고 있지는 않은지 → 만료 시각을 확인하고 있는지 |
| 한 건 조회는 막혔는데 **목록**에 남의 자료가 섞인다 | `lib/domain/query.ts` 의 `buildTaskWhere()` 에 소유자 조건이 들어갔는지 → 목록과 한 건 조회가 서로 다른 코드 경로인지 → 응답 전체를 열어 남의 ID 가 하나도 없는지 |
| 거절은 되는데 상대 자료가 조금 바뀌어 있다 | 주인 확인 전에 저장부터 하고 있지 않은지 → `UPDATE … WHERE id=$1 AND user_id=$2` 형태인지 → 거절 전후 건수를 세어 비교 |
| 같은 비밀번호인데 저장값이 똑같이 나온다 | 계정마다 다른 소금값을 쓰는지 → 고른 방법이 소금값을 자동으로 붙이는지 → 단순 해시 한 번으로 끝내고 있지 않은지 |
| 로컬은 되는데 배포하면 로그인이 안 된다 | 쿠키 `Secure` 속성과 HTTPS → 배포 환경변수 `DATABASE_URL` 등록 여부 → Production Branch 가 `main` 인지 |
| 무료 DB 가 쉬었다 깨어나며 첫 요청이 느리다 | 과제 6에서도 관찰된 현상. 재현 시각과 소요 시간을 기록 |
