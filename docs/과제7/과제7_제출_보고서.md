## 2. 과제 6에서 이어 만든 내용

과제 6의 계획·할 일·실행 기록·돌아보기 구조와 기존 자료를 삭제하지 않고 같은 저장소·Vercel 프로젝트·Supabase PostgreSQL에서 이어 개발했다. 사용자가 직접 만든 소유자 계정에 기존 계획 2개·할 일 5개·돌아보기 1개를 귀속했다.

## 3. 인증 구현

- 아이디·비밀번호 가입과 로그인
- bcryptjs 3.0.3, cost 12 비밀번호 해시
- DB에 SHA-256 해시만 저장하는 7일 서버 세션
- 로그아웃과 비밀번호 변경 시 이전 세션 즉시 폐기
- 세션 사용자 ID를 기준으로 목록·검색·집계·조회·수정·삭제 차단
- 응답 DTO로 비밀번호·세션·소유자 내부 필드 제외
- 일간·주간·월간에서 할 일을 끌어 놓아 날짜 변경(소유자 조건 강제)
- 시작·종료 시각을 바탕으로 예상·실제 시간을 분 단위로 서버 자동 계산
- 공개 로그인·회원가입 선택 화면, 계정 찾기, 비밀번호 보기와 즉시 처리 상태
- 계획 연결 선택형 할 일과 시작일·마감일 날짜 범위

## 6. 남은 제한

- 로그인 시도 횟수 제한·계정 잠금·CAPTCHA가 없다.
- 비밀번호 찾기는 등록 정보 일치 방식이며 이메일 소유 확인·일회용 링크 발송은 없다.
- 관리자용 세션 강제 종료와 감사 로그가 없다.

핵심 제출 범위인 가입·로그인·즉시 세션 폐기·사용자별 자료 차단은 구현하고 배포 환경에서 검증했다.
