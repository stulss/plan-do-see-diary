일반 문자열 패턴 검색은 `docs/과제7/검증안내서.md` 안에 적어 둔 **검사 명령 자체**만 찾았다. 실제 환경 변수 값과 일치한 항목은 없다.

## 3. 인증·세션·자료 격리 원본

실제 공개 배포 검증의 상태코드는 `auth-isolation-results.json`에 있다.

- 가입 201, 중복 가입 409, 미로그인 자료 API 401
- 로그아웃 전 `/api/tasks` 200, 로그아웃 뒤 같은 주소·방식의 이전 세션 401
- 다른 계정 자료 읽기·수정·삭제가 양방향 모두 404
- 거절 전후 상대 자료 1건 유지, 양방향 목록 유출 0건
- 자격증명과 세션 값 기록 없음
