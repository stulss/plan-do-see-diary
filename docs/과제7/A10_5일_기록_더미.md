# A10 5일 사용 기록 — 더미 입력용

> **더미 파일이며 제출 증거가 아니다.** 앱의 계획·할 일·실행 기록을 생성하지 않는다.
> 실제 사용을 시작하면 `docs/과제7/5일_사용기록.md`에 사용자가 직접 입력한다.

## 고정 항목

| 항목 | 값 |
|---|---|
| 질문 | 하루에 계획한 시간과 실제로 쓴 시간의 차이를, 계획 규칙을 바꿔서 줄일 수 있는가? |
| 지표 | 하루 시간 오차율 |
| 단위 | 퍼센트(%) — 원자료는 분 |
| 계산 | `(실제 분 합 - 예상 분 합) ÷ 예상 분 합 × 100` |

| 항목 | 값 |
|---|---|
| 변경 시각 | `(Asia/Seoul 실제 시각)` |
| 변경 전 규칙 | 하루 할 일 3건까지, 각 할 일 예상 시간 60분 이하 |
