## 비밀값 스캔 (제출 전 필수)

```bash
git log -p --all | rg -n "postgres(q[l])?://\S+@|CLIENT[_]SECRET\s*=|GOCSPX-|BEGIN [A-Z ]*PRIVATE KEY"
rg -n --hidden -g "!node_modules/**" -g "!.git/**" -g "!.env*" "postgres(q[l])?://\S+@|CLIENT[_]SECRET\s*=|GOCSPX-|BEGIN [A-Z ]*PRIVATE KEY" .
rg -n "process\.env\.NEXT_PUBLIC_" app lib
git check-ignore -v .env.local
```

앞의 세 명령은 **아무것도 나오지 않아야** 하고, 마지막 명령은 `.env.local` 이 무시 목록에 있음을 보여야 한다. 2026-09-02 로컬 검사에서 각각 0건·0건·0건과 무시 설정을 확인했다.
