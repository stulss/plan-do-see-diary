## 2. 절차

1. GitHub 저장소 생성 후 소스 푸시 (공개 저장소 — 소스 주소로 제출)
2. Vercel Marketplace에서 Supabase 인스턴스를 만들고 프로젝트에 연결
3. `POSTGRES_URL_NON_POOLING` 직접 연결로 `schema.sql` 적용 (표 6개, 계획 수정 트리거, 완료 기본키 제약)
4. 앱은 Vercel이 자동 제공하는 서버 전용 `POSTGRES_URL` 사용 (`NEXT_PUBLIC_*` 접속 문자열 금지)
5. 배포 후 **새 시크릿 창**에서 결과물 주소와 소스 주소를 각각 열어 로그인 없이 열리는지 확인 (C01)
