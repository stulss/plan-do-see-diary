# 과제 요구사항 1:1 매핑

과제 6 원문의 통과 기준 44개 전부와, 학생이 스스로 점검해야 하는 항목을 구분해 정리한다.
상태 표기: ☐ 미착수 / ◐ 진행 / ☑ 완료

## A. 필수 통과 기준 (44개)

### 카드 1 — 계획 세우기

| ID | 요구 | 구현 위치 | 상태 |
|---|---|---|---|
| T06-C04 | 계획에 기간이 저장된다 | `plan.start_date`, `plan.end_date` | ☑ |
| T06-C05 | 계획에 우선순위가 저장된다 | `plan.priority` | ☑ |
| T06-C06 | 계획에 성공 기준이 저장된다 | `plan.success_criteria` | ☑ |
| T06-C07 | 계획에 예상 시간이 저장된다 | `plan.estimate_minutes` (분) | ☑ |
| T06-C08 | 고쳐도 고치기 전 계획이 남는다 | `plan_revision` + BEFORE UPDATE 트리거, 계획 상세의 이력 목록 | ☑ 실제 수정 이력 1건 이상 확인 |

### 카드 3 — 실제로 한 일 적기

| ID | 요구 | 구현 위치 | 상태 |
|---|---|---|---|
| T06-C23 | 시작 시각 저장 | `run_log.started_at` | ☑ |
| T06-C24 | 끝난 시각 저장 | `run_log.ended_at` | ☑ |
| T06-C25 | 실제로 걸린 시간 저장 | `run_log.actual_minutes` (분) | ☑ |

### 카드 4 — 돌아보기

| ID | 요구 | 구현 위치 | 상태 |
|---|---|---|---|
| T06-C28 | 계획 수 = 지우지 않은 할 일 수 | `COUNT(deleted_at IS NULL)` | ☑ |
| T06-C29 | 완료 수 = 그중 완료 상태 수 | `task_completion` 조인 | ☑ |
| T06-C30 | 지연 수 = 미완료 AND 마감일 < 서울 오늘, 완료 건 중복 카운트 금지 | `(now() AT TIME ZONE 'Asia/Seoul')::date` 기준 | ☑ |
| T06-C31 | 막힘 수 = 막힌 이유가 하나라도 적힌 할 일 수 | `COUNT(DISTINCT run_log.task_id WHERE blocker_reason <> '')` | ☑ |
| T06-C32 | 예상 합계·실제 합계·차이(실제−예상), 없으면 0 | 분 단위 SUM, `COALESCE(...,0)` | ☑ |
| T06-C83 | 집계 숫자를 눌러 근거 기록으로 이동 | 집계·목록이 같은 조건 생성 함수 공유 | ☑ 자동 검사·실제 화면 확인 |
| T06-C33 | 고칠 점 한 건이 다음 계획으로 넘어간다 | `review.next_action` → `plan.carried_from_review_id` | ☑ 실제 이월 계획 확인 |
